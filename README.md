# Radical Castle

Radical Castle (1986), a shareware adventure by Christopher Kent Wigginton made with World Builder, running on an emulated Macintosh Plus in the browser.

Open the page, tap **Play**, and the game is on screen. On a phone, hold it sideways: the Mac screen fills the display, with a Click button on the left, a trackpad on the right, and a keyboard button in the corner. Tapping the screen clicks too. It also works on computers with your own mouse and keyboard.

`index.html` is the whole thing in one file: a 68000 CPU and Mac Plus hardware emulator written in JavaScript, plus a snapshot of the machine already sitting at the game's title screen.

The Macintosh Plus ROM and System software included in the snapshot are Apple's copyrighted software.
